## 📖 About This Challenge

Welcome to my **SQL 30 Days Challenge** repository! 👋

This repository documents my journey of learning **SQL with PostgreSQL** through a structured 30-day course.

Each day contains practical SQL queries, notes, exercises, assignments, and hands-on database practice. The challenge starts with SQL fundamentals and gradually progresses toward advanced SQL concepts, analytical queries, joins, window functions, and a final real-world SQL project.

The goal is to build a strong foundation in SQL and develop practical problem-solving skills through consistent hands-on practice.
