## 📖 About This Challenge

Welcome to my **SQL 30 Days Challenge** repository! 👋

This repository documents my journey of learning **SQL with PostgreSQL** through a structured 30-day course.

Each day contains practical SQL queries, notes, exercises, assignments, and hands-on database practice. The goal is to build a strong foundation in SQL and gradually move toward more advanced database concepts.

---

## 🎯 Objectives

Through this challenge, I aim to:

* 🧠 Build a strong foundation in SQL
* 🗄️ Master database querying with PostgreSQL
* 💻 Practice writing SQL queries regularly
* 🧩 Improve problem-solving skills
* 📊 Work with real-world style datasets
* 🔄 Understand data manipulation and database operations
* 🚀 Prepare for Data Analyst and Data Science roles
